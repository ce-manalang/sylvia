<objective>
Build the core conversation flow UI with physical card metaphor. Users progress through 3-level question hierarchy via swipe/tap, can skip sensitive questions, set optional timers, and see onboarding hints on first use.

Purpose: Deliver the central interaction pattern -- the card-by-card conversation experience that makes users feel like they're going deeper. This is the emotional core of the app.

Output: Full session screen with animated card transitions, level progression, skip, timer, and onboarding.
</objective>

  <name>Create session flow hook and swipe gesture hook</name>
  <files>
    src/hooks/useSessionFlow.ts
    src/hooks/useSwipeGesture.ts
    src/hooks/useOnboarding.ts
  </files>
  <action>
    1. Create src/hooks/useSessionFlow.ts:
       - Input: sessionId, questions array
       - State: currentIndex, currentQuestion, currentLevel, isComplete
       - advanceToNext(): increment index, update session in Dexie
       - skipQuestion(): add to skippedQuestions, advance
       - getProgress(): { current, total, level, levelProgress }
       - isSessionComplete: true when index >= questions.length
       - Return all state and actions

    2. Create src/hooks/useSwipeGesture.ts:
       - Input: ref to element, callbacks { onSwipeLeft, onSwipeUp, onTap }
       - Track touch/mouse start position
       - Detect swipe direction (horizontal > 50px threshold, vertical > 50px)
       - Detect tap (< 10px movement, < 300ms duration)
       - Provide transform values for animation (translateX, translateY, rotation)
       - Support both touch events and mouse events for desktop
       - Return { gestureState, handlers }

    3. Create src/hooks/useOnboarding.ts:
       - Check localStorage for 'onboarding:session:complete'
       - Track which tooltips have been shown (swipe, skip, journal)
       - markTooltipSeen(key): mark individual tooltip as seen
       - completeOnboarding(): mark all as complete
       - Return { shouldShowTooltip(key), markTooltipSeen, isFirstSession }
  </action>
